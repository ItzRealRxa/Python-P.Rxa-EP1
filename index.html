03

Install Python

  1. ចូលទៅកាន់ Python.org
  2. Download Python Version ចុងក្រោយ
  3. Tick “Add Python to PATH”
  4. ចុច Install Now
IMPORTANT ✅

Add Python to PATH = អោយ Windows ស្គាល់ Python
